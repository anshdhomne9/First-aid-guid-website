🚑 First Aid Guide Website

 📌 Overview

This project is a simple and responsive **First Aid Guide Website** designed to provide quick help during emergency situations.
It helps users understand basic first aid steps before professional medical assistance arrives.

---

 🎯 Features

* 🩺 Emergency First Aid Topics (Burns, Bleeding, Fracture, etc.)
* 📱 Fully Responsive Design (Mobile + Desktop)
* 🎨 Modern UI with attractive cards and hover effects
* ❓ Interactive FAQ Section (No JavaScript used)
* 🔍 Search bar (UI ready)
* 📌 Clean layout using Bootstrap

---

 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Font Awesome Icons

 ⚙️ How It Works

* Each card represents a **first aid situation**
* Users can click “Learn FirstAid” (future scope)
* FAQ section uses **CSS checkbox toggle technique**
* No JavaScript is required for basic interactivity
